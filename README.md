# Expense Tracker

An Android application to track daily income and expenses with a clean Material Design interface.

## Features

* Add income and expense entries
* View total balance
* Simple and user-friendly interface
* Material CardView based design
* Portrait mode support

## Tech Stack

* Kotlin
* Android Studio
* XML Layouts
* Material Components

## Project Structure

* `app/src/main/java` – Kotlin source code
* `app/src/main/res/layout` – XML layouts
* `app/src/main/res/drawable` – Backgrounds and drawable resources
* `app/src/main/res/values` – Colors, strings, and themes

## How to Run

1. Clone the repository.
2. Open the project in Android Studio.
3. Sync Gradle files.
4. Run the app on an emulator or Android device.
